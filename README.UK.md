# Neovim IDE 2.2.0

[English](README.md)

Термінальний редактор із вкладками файлів, плаваючим провідником, пошуком команд
і мовними інструментами. Збережено звичну стартову сторінку, темні теми та роботу
з вкладками. У версії 2 сесії, термінали, коментування й сніпети використовують
вбудовані можливості Neovim.

## Вимоги та встановлення

- Neovim **0.11.3+**; конфігурацію перевірено на **0.11.5**.
- Git для плагінів і ripgrep (`rg`) для пошуку файлів і тексту.
- Компілятор C для парсерів Tree-sitter; `make` вмикає необов'язковий нативний сортувальник Telescope.
- Nerd Font для піктограм і термінал із підтримкою 24-бітного кольору.
- Середовища виконання й сервери лише для потрібних мов. Декілька серверів для
  вебмов і Python потребують Node.js; інструменти Python, Go та C/C++ мають власні вимоги.
- Alacritty потрібен лише для окремого вікна редактора. Системний буфер обміну
  використовує доступний у цій ОС провайдер (`:checkhealth vim.provider`).

Перед встановленням збережи резервну копію наявного `~/.config/nvim`. Дані та стан
редактора варто залишити, доки не перевіриш сесії й плагіни. Клонуй у вільний каталог:

```sh
git clone https://github.com/valsorym/nvim-ide.git ~/.config/nvim
nvim
```

Перший запуск встановлює плагіни. Наступні запуски автоматично не перевіряють
оновлення й не встановлюють мовні сервери. Підтримку мов встанови явно:

```vim
:ParsersInstall
:LanguageToolsInstall
```

Друга команда встановлює весь підтримуваний набір серверів. Щоб вибрати окремі,
скористайся `:Mason` або `:LspInstall pyright lua_ls`. Для збирання парсерів потрібні
компілятор та інтернет. Після встановлення мовних інструментів перезапусти редактор.
`:Lazy restore` відновлює ревізії з `lazy-lock.json`;
оновлення запускаються явно через `:Lazy update`.

## Українські розкладки клавіатури

Командні клавіші відповідають фізичним позиціям QWERTY.
**Типово вибрано `mac` незалежно від ОС**:

| Значення | Фізична клавіша `b` | Фізична клавіша `s` |
| --- | --- | --- |
| `mac` (типово) | `і` / `І` | `и` / `И` |
| `windows` | `и` / `И` | `і` / `І` |

Вибери розкладку до запуску, наприклад у налаштуваннях оболонки:

```sh
export NVIM_IDE_UKRAINIAN_LAYOUT=mac
# Для української розкладки з розташуванням Windows:
export NVIM_IDE_UKRAINIAN_LAYOUT=windows
```

Альтернатива — параметр у `init.lua` **перед** `require("config.langmap").setup()`:

```lua
vim.g.nvim_ide_ukrainian_layout = "mac" -- або "windows"
```

Явне значення Lua має пріоритет над змінною середовища. Після зміни перезапусти
Neovim. Параметр задає розташування клавіш, не змінює розкладку ОС і не визначає
її автоматично за назвою системи.

`<leader>` — **Пробіл**. `Пробіл wD`, `Пробіл цВ`, `Пробіл wВ` і `Пробіл цD` однаково
видаляють поточну сесію. Звичайні команди на кшталт `dw` також працюють на тих самих
фізичних клавішах. Українські відповідники команд створюються під час реєстрації
комбінацій, зокрема для відкладено завантажуваних плагінів і локальних меню.
Легенда показує лише англійський запис. Текст у режимі вставлення, пошуку й рядку
Ex-команд не транслітерується. Комбінації Ctrl/Alt залежать від кодів, які передає
термінал; цей параметр не перехоплює скорочення термінала чи ОС.

## Клавіші та групи команд

`Пробіл Пробіл` відкриває пошук у легенді, `Пробіл ?` — вибір групи.
Клавіші натискаються послідовно. Великі літери потребують Shift.
Нижче наведено всі налаштовані глобальні комбінації. `n` — звичайний режим,
`x` — візуальне виділення, `o` — очікування руху після оператора, `i` — вставлення.
Вбудовані команди Vim залишаються доступними.

`Пробіл h` / `:KeymapHelp` відкриває довідку з клавіш у центрованому плавучому
вікні: приблизно 90% ширини та 85% висоти термінала. Розмір автоматично
підлаштовується при зміні розміру термінала, а вікна коду зберігають свої розміри.
У рамці показані мова, кількість результатів і підказки клавіш; закриття повертає
фокус у вікно, з якого відкрили довідку.
Буфер доступний лише для читання: усі налаштовані глобальні комбінації
згруповані за призначенням, поруч зазначені режим і опис. Також є клавіші
локальних меню й основні вбудовані команди Vim. Довідка завантажується на вимогу
й не завантажує плагіни, клавіші яких описує. Легенда через `Пробіл Пробіл`
залишається доступною для пошуку й виконання дій.

У довідці `/` відкриває буквальний фільтр: введи слово або кілька слів і натисни
Enter. Пошук охоплює англійські та українські описи й назви груп одночасно,
незалежно від мови відображення. Наприклад, `копіювати` або `copy` знаходить дії
копіювання. Мають збігтися всі слова; `c` очищає фільтр. `e` вибирає англійську,
`u` — українську, `[[` / `]]` переходять між розділами, `q` / Esc закриває
довідку. Enter на записі не виконує описану дію. Звичайне прокручування,
виділення й копіювання Vim працюють; `g/` починає звичайний пошук у видимому
тексті, а `n` / `N` його повторюють.

Типова мова — англійська. `:KeymapHelp uk` одразу відкриває українську; вибір
запам’ятовується до завершення поточного процесу Neovim. Для постійного вибору
додай `vim.g.nvim_ide_help_language = "uk"` в `init.lua`. Цей параметр незалежний
від розкладки ОС та `nvim_ide_ukrainian_layout`; самі комбінації завжди записані
англійськими клавішами. Повний перелік вбудованих команд доступний через
`:help index`, а `g?` показує всі активні клавіші дерева файлів.

### Вбудоване редагування та локальні меню

Використовуй `hjkl`, `w/b/e`, `f/t`, `ciw`, `dap`, `y/p`, `u`, `Ctrl-r` і текстові
об'єкти як у Vim. `gc` коментує рух або виділення, `gcc` — рядок. `=` вирівнює
відступи, `gq` переносить текст. Вікнами керує `Ctrl-w`, вкладками — `gt`/`gT`.
`Ctrl-t` повертає через стек тегів, `Ctrl-o`/`Ctrl-i` — через історію переходів.
Команди `:q`, `:new`, `:split`, `:vsplit` зберігають звичне значення. `:Q` закриває
поточну вкладку редактора з вибором зберегти/відкинути/скасувати; `:Q!` відкидає зміни.

- Доповнення: `Ctrl-n`/`Ctrl-p` обирають варіант, `Ctrl-Space` запитує доповнення,
  `Tab` приймає вибраний/перший варіант або переходить до наступного поля сніпета,
  `Shift-Tab` — до попереднього. `Enter` приймає лише явно вибраний варіант, інакше
  вставляє новий рядок. `Ctrl-e` закриває список. Доповнення командного рядка — вбудоване.
- Telescope: `Ctrl-n`/`Ctrl-p` або `Ctrl-j`/`Ctrl-k` переміщують вибір, `Tab` позначає
  декілька результатів, `Enter` підтверджує. Файл відкривається у новій або вже наявній
  вкладці. Перший `Esc` виходить зі вставлення, наступний закриває вікно пошуку.
- Провідник: `Enter` відкриває файл у вкладці, `t` розгортає каталог, `T` згортає,
  `C` робить вибраний каталог коренем, `B` бере поточний робочий каталог,
  `P` переходить до батьківського, `gR` запитує шлях кореня. `R` оновлює, `H` перемикає
  приховані файли, `F` фільтрує, `X` скидає фільтр; `n/d/r/c/x/p` створюють/видаляють/
  перейменовують/копіюють/вирізають/вставляють. `g?` показує довідку, `Esc` закриває провідник.
- Історія проєктів (`Пробіл bh`): `/` фільтрує шляхи, `j/k` переміщують вибір,
  `Enter` відкриває проєкт, `d` прибирає запис, `C` очищує історію, `q` закриває вікно.
- Список вкладок: `j/k` переміщують вибір, `/` або `i` шукає, `Enter` переходить,
  `d` закриває із захистом незбережених змін, `q` закриває список.
- Термінал: `Ctrl-\ Ctrl-n` повертає у звичайний режим. Повторна команда цього
  термінала приховує/показує буфер. Процеси повторно використовуються за каталогом і завданням.
- Copilot необов'язковий і спочатку вимкнений. `Пробіл cpt` вмикає його,
  `Пробіл cpa` налаштовує вхід. У режимі вставлення `Ctrl-g Ctrl-y` приймає,
  `Ctrl-g Ctrl-n`/`Ctrl-g Ctrl-p` перемикають, `Ctrl-g Ctrl-e` відхиляє підказку.

## Підтримка мов

Збережено налаштування типів файлів для всіх раніше підтримуваних мов. Сервер
запускається лише за наявності виконуваного файла й відкритого підтримуваного
документа звичайного розміру.

| Файли | Мовні сервери | Зовнішнє форматування (`Пробіл df`) |
| --- | --- | --- |
| Python | pyright | Ruff: імпорти й форматування; резервно isort/Black |
| JavaScript, TypeScript, JSX, TSX | ts_ls, emmet_ls | Prettier |
| Vue | vue_ls + ts_ls із плагіном Vue для TypeScript | Prettier |
| HTML | html, emmet_ls | Prettier |
| Django HTML | html, emmet_ls | Вбудовані `=` / `gq`; зовнішнє вимкнено |
| CSS, SCSS, Less | cssls; emmet_ls для CSS/SCSS | Prettier |
| Sass | Вбудовані синтаксис і відступи | Вбудований `=` |
| Go | gopls | gofmt |
| C, C++ | clangd | clang-format |
| JSON, JSONC | jsonls зі SchemaStore | Prettier |
| YAML | yamlls зі SchemaStore | Prettier |
| Lua | lua_ls | StyLua |
| Shell | bashls | shfmt |
| Dockerfile | dockerls | Вбудований `=` |
| Markdown | marksman | Prettier |
| reStructuredText | Вбудований синтаксис і локальний рендерер | Вбудований `gq` |
| TOML, XML, INI, Make, звичайний текст | Вбудовані налаштування типів файлів | Вбудовані `=` / `gq` |

LSP надає доповнення, визначення, посилання (`grr`), перейменування та діагностику.
Файли без маркерів проєкту використовують режим одного файла, якщо сервер його
підтримує. HOME, `/` і `/tmp` не використовуються як корені індексації.
Без відповідного LSP команди `gd`/`gD` зберігають нативну навігацію Vim,
а Ctrl-клік використовує теги. Підсвітка TODO завантажується після першої
TODO-команди або `]t`/`[t`.
Таблиця описує інтеграції, а не встановлені середовища виконання. mypy і flake8 —
необов'язкові зовнішні інструменти; фоновий лінтинг не запускається.
`:PythonToolsStatus` показує наявність програм, а не результати перевірки коду.

Python-середовище визначається для кожного проєкту: `.venv`, `venv`, `env`, `.env`,
потім успадковане `VIRTUAL_ENV`, потім системний Python. `Пробіл cvc` вибирає каталог
середовища, `Пробіл cvd` повертає поточний проєкт до системного Python. Загальний
PATH і клієнти pyright інших проєктів не змінюються. Для Vue встанови через Mason
`vue-language-server` і `typescript-language-server`. Для C/C++ надай
`compile_commands.json`, якщо він потрібен проєкту.

### Форматування та заміна

`Пробіл fs` / `:FindInBuffer` відкриває плавуче вікно пошуку в поточному
буфері, включно з незбереженим текстом. Вводь буквальний однорядковий текст:
символи `.`, `#`, `/` та `[` не потребують екранування. Регістр враховується
за налаштуваннями Vim `ignorecase` і `smartcase`. Результати оновлюються після
короткої паузи введення; `Ctrl-n` / `Ctrl-p` показують наступний / попередній
збіг із переходом по колу. Enter переходить до збігу й закриває вікно;
потім звичайні `n` / `N` повторюють цей пошук. Esc скасовує перегляд і
повертає початкову позицію курсора та прокручування.

`Пробіл fc` / `:ReplaceInBuffer` додає поле заміни. Enter у Find переходить
до Replace; Enter у Replace або `Ctrl-r` у будь-якому полі замінює один збіг
і переходить далі. `Ctrl-a` явно замінює всі збіги в цьому буфері. Tab /
Shift-Tab перемикають поля й список; Enter у списку переходить до збігу без
заміни. `Ctrl-u` очищає активне поле. Порожня заміна видаляє збіги. Текст заміни
буквальний, включно з `&`, `~` та зворотним слешем. Кожна дія заміни — один
крок undo: закрий вікно й натисни `u`, щоб скасувати її. Діалог не зберігає
файлів. Esc залишає вже виконані заміни.

Перегляд містить до 2 000 збігів із позначкою `2000+`, якщо спрацювала межа;
заміна всіх охоплює весь буфер. У режимі великих файлів пошук запускається
лише явною дією Enter, переходу чи заміни, а не після кожної паузи введення.
Звичайні `/текст` і `:%s#шаблон#заміна#g` доступні для шаблонів Vim.

Типово форматування ручне. `Пробіл df` асинхронно обробляє документ у пам'яті й
застосовує результат лише тоді, коли буфер за цей час не змінився. Форматери
отримують stdin і не перезаписують файл на диску. Python-інструменти проєкту й
`node_modules/.bin` мають пріоритет над PATH. Якщо зовнішнього форматера немає,
використовується під'єднаний LSP із підтримкою форматування.

`Пробіл ds` перемикає форматування під час збереження для поточного процесу.
Збереження тоді очікує до 1,5 секунди на кожний форматер; у разі помилки текст
не змінюється. Для постійного вибору задай `vim.g.format_on_save = true` до setup.
Встановлюй лише потрібні інструменти: наприклад, `python -m pip install ruff`
у віртуальному середовищі проєкту або `:MasonInstall ruff`. Prettier можна встановити
як залежність розробки проєкту.

Для Python типово використовується Ruff: упорядкування імпортів і форматування
з межею 79 колонок та збереженням стилю лапок. Якщо Ruff відсутній, використовуються
наявні isort/Black. `Пробіл di` впорядковує імпорти через Ruff або isort,
`Пробіл db` явно запускає Black. Щоб віддати перевагу попередньому ланцюжку,
задай `vim.g.nvim_ide_python_formatter = "black"` до setup і встанови `black isort`
у середовищі проєкту. Ruff тут працює як форматер; додатковий фоновий LSP-лінтер
не вмикається.
Пробіли наприкінці рядків прибирає лише `Пробіл dx`; звичайне збереження не псує
жорсткі переноси Markdown. Для шаблонів Django використовуй вбудовані команди.

`Пробіл fr` шукає **буквальний текст з урахуванням регістру**. Познач рядки результатів
через `Tab`, натисни `Ctrl-r` у рядку пошуку або `r` у звичайному режимі, введи заміну.
Без позначень використовуються всі вже зібрані рядки результатів. Переглянь запит
підтвердження. Зміни залишаються в буферах із можливістю скасування; перевір їх через
`:ls` і збережи через `:wall`. Уже змінені, захищені від запису та великі буфери,
а також рядки, що змінилися після пошуку, пропускаються. `Пробіл fR` включає
ігноровані файли, крім `.git`. Для регулярних виразів доступна звичайна `:%s`.

## Швидкодія та великі файли

Буфери понад **1 MiB** або **20 000 рядків** переходять у режим великих файлів.
Для такого буфера вимикаються Tree-sitter, під'єднання LSP, доповнення, діагностика,
згортання та напрямні відступів. Інші буфери зберігають мовні інструменти.
Текст і звичайне редагування доступні. `Пробіл xL` / `:LargeFileInfo` показує режим.
Буфер, що росте, перевіряється після виходу зі вставлення та після запису.
Щоб переоцінити зменшений файл, відкрий його повторно. Межі задаються до setup:

```lua
vim.g.nvim_ide_large_file_bytes = 2 * 1024 * 1024
vim.g.nvim_ide_large_file_lines = 30000
```

Доповнення шукає слова лише в поточному буфері. Python-діагностика охоплює відкриті
файли. На старті завантажується лише вибрана тема; меню, структура коду й менеджери
інструментів — за потреби. Відступи задають правила типу файла замість Tree-sitter.
Невикористовувані провайдери віддалених плагінів Python/Ruby/Perl/Node вимкнено
до завантаження runtime. LSP і Copilot запускають власні процеси. Для додаткового
плагіна можна ввімкнути провайдер до запуску, наприклад:
`vim.g.nvim_ide_enabled_providers = { python3 = true }`.
Українські відповідники команд створюються через API реєстрації клавіш; після
оновлення Neovim або плагінів їх слід перевіряти. Цей реліз перевірено на Neovim 0.11;
для 0.12 потрібна окрема перевірка сумісності Tree-sitter.

Вкладка переміщується лише під час переходу буфера до зміненого стану. Щоб порядок
вкладок залишався сталим:

```lua
vim.g.nvim_ide_move_modified_tabs = false
```

## Сесії, вкладки й теми

Пошук файлів, провідник і перехід до визначення відкривають або повторно використовують
вкладки; звичайні спліти працюють. `Пробіл tq` запитує перед втратою незбереженого тексту.
`Пробіл tc` закриває лише вкладки, усі вікна яких не містять змінених буферів.
Приховані сторонні буфери залишаються. `F2` записує файл і за потреби запитує ім'я.

Сесії використовують `:mksession` у `stdpath("state")/sessions-v2`. Зберігаються файли,
каталоги, вкладки, вікна й згортання, **але не незбережений текст буферів**. Автозбереження каталогу на виході
вмикається лише після `SessionSave` або успішного відновлення сесії в цьому
процесі редактора. Короткий запуск `nvim file` не перезапише збережену
проєктну сесію. Попередня версія залишається у файлі `.vim.bak`.
Відновлення — явне. `Пробіл wD` видаляє поточну
сесію й забороняє її автоматичне відтворення до явного `Пробіл ws`. Відновлення сесій
і перемикання робочих просторів блокуються за наявності змінених буферів.
`Пробіл wa` називає поточний каталог, `Пробіл ww` відкриває збережені робочі простори.

Для сесій версії 1 скористайся `Пробіл wL` (`:SessionLegacy`), після відновлення —
`Пробіл ws`. Старі файли залишаються. Назви робочих просторів додай через `Пробіл wa`.

`Пробіл ut` попередньо показує теми, `Пробіл us` обирає та запам'ятовує. Назва
зберігається в каталозі стану Neovim; старий `.last_colorscheme` використовується
як резервне джерело. Теми: Catppuccin, Tokyo Night, Gruvbox Material, Kanagawa,
Nord, OneDark. Після редагування конфігурації перезапусти редактор: автоматичного
повторного виконання Lua-файлів немає.

## Консоль, окреме вікно та tmux

Запускай `nvim`, `nvim file` або `nvim -p first.py second.py` у сумісному терміналі.
Для окремого вікна Alacritty в Linux:

```sh
mkdir -p ~/.local/bin ~/.local/share/applications
install -m 755 ~/.config/nvim/bin/nvim-ide ~/.local/bin/nvim-ide
install -m 644 ~/.config/nvim/extras/nvim-ide.desktop ~/.local/share/applications/nvim-ide.desktop
nvim-ide -p first.py second.py
```

Додай `~/.local/bin` до PATH. Скрипт розгортає вікно засобами Alacritty й не потребує
`wmctrl`. `nvim-ide --terminal file` працює в поточній консолі. Обидва способи
використовують ту саму конфігурацію та приймають звичайні аргументи Neovim.

Для правильних кольорів у tmux підключи фрагмент у `~/.tmux.conf`:

```tmux
source-file ~/.config/nvim/extras/tmux.conf
```

Виконай `tmux source-file ~/.tmux.conf`, від'єднайся/під'єднайся до сесії й створи
нову панель. Фрагмент задає `default-terminal=tmux-256color` та RGB для клієнтів
Alacritty й `xterm-256color`. Якщо зовнішній термінал має інше ім'я, додай його.
Залишай справжнє значення TERM: не підміняй його в налаштуваннях оболонки.
Опис terminfo `tmux-256color` потрібен на хості, зокрема віддаленому через SSH.
Додаткові випадки описано в [FAQ tmux про кольори](https://github.com/tmux/tmux/wiki/FAQ).

`:checkhealth nvim_ide` перевіряє редактор, розкладку й термінал;
`:checkhealth vim.lsp` — мовні клієнти. Колір і шрифт — окремі налаштування:
якщо бракує піктограм, вибери Nerd Font. Віртуальна консоль Linux може не підтримувати
палітру й символи графічного емулятора термінала.

## Перехід із версії 1

Версія 2 групує комбінації за діями; користуйся `Пробіл ?` і таблицями вище.
Форматування — `Пробіл d`, перевірки — `Пробіл x`, термінали — `Пробіл r`.
Доступні звичайні `z` для згортання, `Ctrl-w` для вікон, `Ctrl-t` для тегів,
`Ctrl-k` для диграфів. Легенда має єдине джерело в `lua/config/keymaps.lua`.

Legendary, дубльовані менеджери сесій, ToggleTerm, LuaSnip і зайві адаптери
форматування замінено локальними модулями та вбудованими API. Збережено мовну
підтримку, провідник, теми, Git-позначки, дерево скасувань і необов'язковий Copilot.
Після оновлення явно встанови сумісні парсери. Перед переходом збережи конфігурацію
і стан; видаляти старі сесії чи масово прибирати системні пакети не потрібно.

## Структура конфігурації

- `init.lua`: типові параметри, розкладка, запуск модулів і lazy.nvim.
- `lua/config/`: клавіші, вкладки, сесії, Python-середовища, форматування, пошук і допоміжні меню.
- `lua/plugins/`: єдине місце налаштування кожного плагіна й умови завантаження.
- `ftplugin/`: відступи, коментарі та текстові параметри окремих мов.
- `lua/nvim_ide/health.lua`: перевірка `:checkhealth nvim_ide`.
- `bin/` та `extras/`: запуск у вікні й інтеграція термінала.
- `lazy-lock.json`: перевірені ревізії плагінів. Версія релізу — `lua/plugins/dashboard.lua`.
